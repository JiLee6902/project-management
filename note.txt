================================================================================
                         GUEST LOGIN WORKFLOW
================================================================================

1. TỔNG QUAN
--------------------------------------------------------------------------------
Guest login cho phép user trải nghiệm app mà không cần đăng ký tài khoản.

GIỚI HẠN:
  - Mỗi session (IP + Fingerprint): tối đa 3 lần login
  - Mỗi IP: tối đa 3 session MỚI trong ngày (khác fingerprint)
  - Mỗi lần login đầu tiên → tạo user + seed data
  - Các lần sau → return user cũ (giữ data)

2. FLOW CHI TIẾT
--------------------------------------------------------------------------------

    [User click "Continue as Guest"]
                  │
                  ▼
    ┌─────────────────────────────────────────────────────────────┐
    │  FRONTEND (Login.jsx)                                       │
    │  - Tạo device fingerprint từ: userAgent + screen + timezone │
    │  - Gọi API: POST /api/auth/guest                            │
    │    Body: { deviceFingerprint: "base64string" }              │
    └─────────────────────────────────────────────────────────────┘
                  │
                  ▼
    ┌─────────────────────────────────────────────────────────────┐
    │  BACKEND - Controller (auth-public.controller.ts)           │
    │  - Lấy IP từ request:                                       │
    │    req.ip || x-forwarded-for || socket.remoteAddress        │
    │  - Gọi authService.guestLogin(ipAddress, fingerprint)       │
    └─────────────────────────────────────────────────────────────┘
                  │
                  ▼
    ┌─────────────────────────────────────────────────────────────┐
    │  STEP 1: TÌM SESSION THEO IP + FINGERPRINT                  │
    │  ─────────────────────────────────────────                  │
    │  SELECT * FROM guest_sessions                               │
    │  LEFT JOIN users ON users.id = guest_sessions.user_id       │
    │  WHERE ip_address = :ip                                     │
    │  AND device_fingerprint = :fingerprint                      │
    │  ORDER BY created_at DESC                                   │
    │  LIMIT 1                                                    │
    └─────────────────────────────────────────────────────────────┘
                  │
          ┌───────┴───────┐
          ▼               ▼
    ┌───────────┐   ┌─────────────────────────────────────────────┐
    │  TÌM THẤY │   │  KHÔNG TÌM THẤY → Go to STEP 2              │
    └───────────┘   └─────────────────────────────────────────────┘
          │
          ▼
    ┌─────────────────────────────────────────────────────────────┐
    │  CHECK: loginCount >= 3?                                    │
    │                                                             │
    │  CÓ (loginCount >= 3):                                      │
    │  ─────────────────────                                      │
    │  → REJECT: "Maximum 3 guest logins reached"                 │
    │                                                             │
    │  KHÔNG (loginCount < 3):                                    │
    │  ───────────────────────                                    │
    │  → UPDATE: loginCount += 1                                  │
    │  → UPDATE: expires_at = NOW + 1 DAY                         │
    │  → Return existing user + generate new tokens               │
    │  → remainingSessions = 3 - loginCount                       │
    │  → [END - RETURN RESPONSE]                                  │
    └─────────────────────────────────────────────────────────────┘

    ════════════════════════════════════════════════════════════════
    NẾU KHÔNG TÌM THẤY SESSION (IP hoặc Fingerprint mới)
    ════════════════════════════════════════════════════════════════
                  │
                  ▼
    ┌─────────────────────────────────────────────────────────────┐
    │  STEP 2: CHECK DAILY LIMIT (số session MỚI trong ngày)      │
    │  ─────────────────────────────────────────────────────      │
    │  SELECT COUNT(*) FROM guest_sessions                        │
    │  WHERE ip_address = :ip                                     │
    │  AND created_at >= TODAY 00:00:00                           │
    │                                                             │
    │  if (count >= 3) {                                          │
    │    throw Error("Max 3 guest sessions per day")              │
    │  }                                                          │
    │                                                             │
    │  Giải thích: Giới hạn tạo 3 USER MỚI/ngày cho mỗi IP        │
    │  (chống spam tạo nhiều account bằng cách đổi fingerprint)   │
    └─────────────────────────────────────────────────────────────┘
                  │
                  ▼

    │  STEP 3: TẠO GUEST USER MỚI                                 │

    │    (ip_address, device_fingerprint, user_id,                │

                  │

3. DATABASE SCHEMA
--------------------------------------------------------------------------------

TABLE: guest_sessions
┌─────────────────────┬──────────────┬─────────────────────────────┐
│ Column              │ Type         │ Description                 │
├─────────────────────┼──────────────┼─────────────────────────────┤
│ id                  │ UUID (PK)    │ Primary key                 │
│ ip_address          │ VARCHAR      │ Client IP address (indexed) │
│ device_fingerprint  │ VARCHAR      │ Browser fingerprint         │
│ user_id             │ UUID (FK)    │ Reference to users table    │
│ expires_at          │ TIMESTAMP    │ Session expiry (extends)    │
│ login_count         │ INTEGER      │ Số lần login (max 3)        │
│ created_at          │ TIMESTAMP    │ Auto                        │
│ updated_at          │ TIMESTAMP    │ Auto                        │
└─────────────────────┴──────────────┴─────────────────────────────┘

TABLE: users (AuthProvider enum)
┌─────────────────────┬──────────────┬─────────────────────────────┐
│ provider            │ ENUM         │ LOCAL, GOOGLE, GITHUB,      │
│                     │              │ GUEST  <-- NEW              │
└─────────────────────┴──────────────┴─────────────────────────────┘

4. SCENARIOS (VÍ DỤ CỤ THỂ)
--------------------------------------------------------------------------------

SCENARIO 1: User mới lần đầu vào
────────────────────────────────
  IP: 192.168.1.100, Fingerprint: "abc123"

  Click Guest → Không tìm thấy session
            → Check daily limit: 0/3 → OK
            → Tạo Guest_AAA (loginCount = 1)
            → Tạo Workspace + Project + Tasks
            → Return tokens, remainingSessions = 2

SCENARIO 2: User quay lại lần 2 (cùng browser)
──────────────────────────────────────────────
  IP: 192.168.1.100, Fingerprint: "abc123"

  Click Guest → Tìm thấy session Guest_AAA (loginCount = 1)
            → loginCount = 1 < 3 → OK
            → UPDATE loginCount = 2, extends expires_at
            → Return Guest_AAA tokens
            → remainingSessions = 1, Data cũ vẫn còn!

SCENARIO 3: User quay lại lần 3
───────────────────────────────
  IP: 192.168.1.100, Fingerprint: "abc123"

  Click Guest → Tìm thấy session Guest_AAA (loginCount = 2)
            → loginCount = 2 < 3 → OK
            → UPDATE loginCount = 3, extends expires_at
            → Return Guest_AAA tokens
            → remainingSessions = 0, Data cũ vẫn còn!

SCENARIO 4: User quay lại lần 4 (HẾT LƯỢT)
──────────────────────────────────────────
  IP: 192.168.1.100, Fingerprint: "abc123"

  Click Guest → Tìm thấy session Guest_AAA (loginCount = 3)
            → loginCount = 3 >= 3 → REJECT
            → Error: "Maximum 3 guest logins reached"

SCENARIO 5: User dùng browser khác (fingerprint khác)
─────────────────────────────────────────────────────
  IP: 192.168.1.100, Fingerprint: "xyz789" (khác abc123)

  Click Guest → Không tìm thấy session với fingerprint này
            → Check daily limit: 1/3 (đã có Guest_AAA) → OK
            → Tạo Guest_BBB mới (loginCount = 1)
            → Tạo Workspace + Project + Tasks riêng
            → Return tokens, remainingSessions = 2

SCENARIO 6: User tạo quá 3 session trong ngày (đổi fingerprint spam)
────────────────────────────────────────────────────────────────────
  IP: 192.168.1.100
  Đã tạo: Guest_AAA (fp: abc), Guest_BBB (fp: xyz), Guest_CCC (fp: 123)
  Fingerprint mới: "999"

  Click Guest → Không tìm thấy session với fingerprint "999"
            → Check daily limit: 3/3 → REJECT
            → Error: "Max 3 guest sessions per day"

5. GIỚI HẠN TÓM TẮT
--------------------------------------------------------------------------------

┌─────────────────────────────────────────────────────────────────┐
│  LIMIT 1: loginCount per Session                                │
│  ───────────────────────────────                                │
│  - Mỗi session (IP + Fingerprint) được login tối đa 3 lần      │
│  - Sau 3 lần → user phải đăng ký account thật                   │
│  - Data vẫn giữ nguyên qua các lần login                        │
│                                                                 │
│  LIMIT 2: Daily Session Count per IP                            │
│  ───────────────────────────────────                            │
│  - Mỗi IP được tạo tối đa 3 session MỚI trong ngày              │
│  - Chống spam bằng cách đổi fingerprint liên tục                │
│  - Reset mỗi ngày (00:00:00)                                    │
└─────────────────────────────────────────────────────────────────┘

6. API ENDPOINT
--------------------------------------------------------------------------------

POST /api/auth/guest

Request:
  Body: { "deviceFingerprint": "string (optional)" }

Response (Success - 200):
  {
    "accessToken": "eyJhbG...",
    "refreshToken": "eyJhbG...",
    "user": { "id": "uuid", "email": "guest_xxx@guest.local", "name": "Guest XXX" },
    "isGuest": true,
    "remainingSessions": 2
  }

Response (Error - 400):
  - "Maximum 3 guest logins reached. Please register for unlimited access."
  - "Maximum 3 guest sessions allowed per device per day. Please register..."
